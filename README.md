Rapport de Classification : Analyse de l'Addiction aux Smartphones

Ce dépôt contient l'implémentation d'une étude prédictive sur les comportements d'utilisation des smartphones. L'objectif est de classifier les niveaux d'addiction des utilisateurs à travers des indicateurs de vie quotidienne et d'utilisation numérique.

- Description du Projet
L'étude repose sur un jeu de données de 7500 entrées. Le travail comprend la préparation des données, le traitement des variables catégorielles et l'application de plusieurs méthodes d'apprentissage supervisé pour comparer leur efficacité.

- Algorithmes Implémentés
Dans ce projet, j'ai développé et évalué les six modèles suivants :

- Random Forest

- K-Nearest Neighbors (KNN)

- Logistic Regression

- Support Vector Classifier (SVC)

- Naive Bayes

- Decision Tree

Synthèse des Résultats
Le modèle Random Forest a obtenu la meilleure précision avec un score de 92.45%. Les modèles KNN et Naive Bayes ont également montré une grande fiabilité avec des scores de précision supérieurs à 90%. L'évaluation a été réalisée en utilisant des matrices de confusion et des courbes ROC pour garantir la validité des prédictions.

Fichiers inclus
